# Omar's library: components + links + assets (ONE public repo, omarjnbz/Assets-)

Single-page library of Omar's components. Output is ONE file, `index.html`, generated by `build.js` from `ui.html` + `items/`. Never edit `index.html` by hand.

When Omar pastes a component (React, Vue, HTML, anything): create `items/<kebab-name>/` with the component file(s), the demo as `demo.tsx` (import path `@/components/ui/<kebab-name>`), `meta.json` (title, source, description, tags, added), then run `node build.js`, then `npm run sync` to commit and push. Keep the code verbatim.
Do not create a second repo or a second UI. Do not install npm packages without asking. Premium registries (React Bits Pro) need Omar's own license key in his environment.

## Links
Omar also keeps a link library (`links.json`, "Links" tab). When he sends websites to save: write the pasted text to a file and run `node link.js --file <file>` (or `node link.js <url> --note ".." --cat ".."`), then `node build.js` happens automatically. Dedup is by host+path. Use existing categories where they fit, else Unsorted. Then commit and push.

## Assets
`assets/` is a live public CDN via jsDelivr (`cdn.jsdelivr.net/gh/omarjnbz/Assets-@main/assets/...`). The Nur Elite client site hotlinks it: NEVER rename, move or delete files under `assets/`, never make this repo private. `gallery.html` + `manifest.json` (rebuilt by the GitHub Action) back the Assets tab. This repo is PUBLIC: do not commit secrets or anything Omar wants private. Push with `gh auth switch -u omarjnbz`.
